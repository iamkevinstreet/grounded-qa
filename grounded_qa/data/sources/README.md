# Approved sources

Drop Markdown or plain-text files here. Each file becomes a set of sections split on headings. A small header
at the top of a file records where it came from and when it took effect:

```
---
title: Fact Sheet #28: The Family and Medical Leave Act
source: https://www.dol.gov/agencies/whd/fact-sheets/28-fmla
effective: 2023-02-01
---
```

For the prototype, use public-domain government guidance only:

- U.S. Department of Labor, Wage and Hour Division fact sheets (dol.gov/agencies/whd/fact-sheets)
- EEOC guidance documents (eeoc.gov/laws/guidance)
- One state's leave statute, pasted as text

`sample-leave-guidance.md` is a made-up example used by the offline smoke evaluation. It is not legal guidance.
Delete it before running against real sources.
