## How each was copied

Each page was read in a browser on Oct 29, 2026, its text extracted to Markdown, and the extract
checked byte for byte against the live page by SHA-256. The only change to the agency's text is the
removal of the "(link is external)" markers the site adds to outbound links, and the stray space
those links leave before a full stop.

## Format

Each file is Markdown below a block of `key: value` lines between `---` fences: `title`,
`publisher`, `source` (the address it was copied from), `revised` (the revision date the page
states), `retrieved` (the copy date), `license`, and `sha256`, the SHA-256 of the text below the
block. The service refuses to start if any text no longer matches its hash, so these files are
never edited by hand: a change goes through the approver routes, or a fresh copy that is checked
again.

This README is not a source; the loader skips it.
